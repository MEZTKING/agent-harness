This project is a game played in the browser (a canvas or plain HTML, no engine download). Plan the
game loop, the controls and the screens (start, play, game over) first, with the shared names in the
first task. Pictures come from the artist role.
Sound: when a sound role is offered, plan only what $2 buys, as tasks for that role: short effects of 0.5 to 3 seconds, and at most one music loop of 30 seconds or less unless the idea is about music. Name each sound by what happens in the game ("the player lands a jump"), set sound_options, and give it an output_path under assets/sounds/. Without a sound role, sound only when the owner wants it, made in code (the Web Audio API).
